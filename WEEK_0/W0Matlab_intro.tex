\section*{1. What is MATLAB?}

MATLAB is a programming environment widely used for numerical computation and data analysis, and engineering tasks. It has an integrated editor where you can write and run scripts.

\section*{2. Exploring the MATLAB Interface}

When you open MATLAB, you'll see several important windows:

\begin{enumerate}
    \item \textbf{Command Window}: in the center, where you can type and immediately execute commands.
    \item \textbf{Toolstrip}: toolbar at the top, lets you open, save, run scritps and more. 
    \item \textbf{Current Folder}: on the left, shows your working directory.
    \item \textbf{Workspace}: shows you current variables and their values
\end{enumerate}

\section*{4. Running the Script}

Click the \texttt{Run} button (green triangle) in the toolbar. MATLAB will ask you to save the script first if it hasn’t been saved yet (see Section \ref{save}). Once saved, the code is run and the result is shown in the \textbf{Command Window}.

\label{save}
\section*{5. Saving the Script}

To save the current script, you can either:
\begin{enumerate}
    \item Click disk icon on the top toolbar.
    \item Press \texttt{Ctrl + S}.
\end{enumerate}
MATLAB scripts are saved with the \texttt{.m} extension.

\section*{6. Reopening a Saved Script}

To open a saved script again, you can either:
\begin{itemize}
    \item Find it in the \texttt{Current Folder} window and double-click it.
    \item Use \texttt{Open} from the toolbar or press \texttt{Ctrl + O} and select the file.
\end{itemize}
